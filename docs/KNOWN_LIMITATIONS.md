# 已知限制

更新日期：2026-10-09。本项目以预览版本维护，以下边界应在使用和报告问题时考虑。

## 文件与编辑

- iOS/iPadOS 导入只复制 Markdown 文件，随后编辑 App 内副本；不会回写来源，不会自动带入相邻图片目录，也没有自建云同步。
- 包含 YAML Front Matter、脚注、目录标记、GitHub 提示块或不受支持 HTML 等内容时，可能退回源码编辑。能渲染某个扩展不代表能在即时编辑模式下安全往返。
- 未编辑文件保留原始字节；即时编辑允许规范化非语义格式，例如列表标记和空格。
- 阅读预览中的任务复选框用于展示状态，不支持点击后同步修改 Markdown。
- 任意远程图片和文档目录外资源不会加载。

## 导出

- PDF 当前固定为 A4；自定义纸张、页码、标题书签和 Tagged PDF 尚未实现。
- DOCX 使用限定范围解析器，不承诺完整 CommonMark 等价。复杂嵌套列表、特殊链接或代码语法需要核对导出结果。
- DOCX Mermaid 为 PNG，数学为 Cambria Math 样式的公式文本，不是 Word 原生 OMML 公式。
- HTML 导出提供语义结构，不保证保留 App 的完整样式、公式排版或 Mermaid 图形。
- Word、Pages、真机导出和长文档／低内存压力需要进一步人工验收。当前验证范围见 [验证记录](VALIDATION.md)。

## 平台与发布

- 真机中文输入、选区与撤销、键盘、旋转、无障碍等体验不能由单元测试或无签名构建证明。
- 当前源码不提供 App Store 购买或商店评价功能。
- macOS 安装包的正式签名、公证与安装验证，以及 iOS/iPadOS 自行签名运行，属于独立步骤。
