# ADR-0002：Markdown 源文件和保存安全

- 状态：Accepted
- 日期：2026-08-24

## 决策

`.md` 是用户持久化资产。所见即所得模式不是独立文档格式，也不得在打开文件时自动重写源文件。

保存必须经过以下门槛：

1. 解析时产生语法覆盖报告；
2. 不受支持且不能原样保留的内容强制源码模式；
3. 编辑后序列化 Markdown；
4. 重新解析并比较语义结构；
5. 校验通过后临时写入并原子替换；
6. 失败时保留原文件和可恢复草稿。

## 非目标

首版不承诺 WYSIWYM 保存后逐字节相同。支持语法可以规范化空格或列表标记，但不得改变文档语义、链接、代码、HTML 原文或资源路径。

未编辑文档在编码时返回原始字节。当前接受 UTF-8（可带 BOM）、UTF-16 LE/BE（必须带 BOM），按原编码回写；其他编码拒绝打开并给出转换提示。

## 测试要求

- CommonMark/GFM 规范语料；
- 中文、Emoji、组合字符和换行；
- 打开后不编辑直接关闭不得写文件；
- parse/serialize/parse 语义等价；
- 已知 Milkdown 往返缺陷回归样例；
- 崩溃、进程终止和磁盘写入失败恢复。
