# Mossmark 隐私说明

更新日期：2026-10-09。适用于本仓库提供的源码版本。

Mossmark 在用户设备上读取、编辑和导出文档。项目代码没有开发者运营的账号系统、自建后端、广告、分析 SDK 或文档上传功能。

## 本机数据

- macOS 文档保存在用户选择的位置；iOS/iPadOS 导入的文档复制到 App 内文档库。
- 阅读设置保存在本机偏好设置中；iOS/iPadOS 最近打开记录及阅读进度也保存在本机。
- 插入的图片复制到文档相邻的 `images/` 目录；导出和分享可能生成临时文件。
- 系统诊断日志可能记录读写字节数或错误信息；公开日志前仍需检查其中的文件路径和其他个人信息。

## 系统服务与外部链接

文件选择、照片选择、打印和分享由 Apple 系统界面提供。用户选择的文件位置或分享目标可能由 iCloud、第三方文件服务或其他 App 管理，其处理方式遵循对应服务的隐私政策。Mossmark 不提供自己的云同步服务。

编辑器的脚本、字体、公式和图表资源离线打包，WebView 禁止联网连接。用户主动打开外部链接、项目主页、问题反馈或本隐私说明时，由系统浏览器访问对应网站；访问 GitHub 等网站时适用该网站的隐私政策。

## 删除与备份

用户可以自行删除文档或导出备份。卸载 iOS/iPadOS App 会影响 App 内文档库，卸载前应备份 Markdown 和关联图片。移除偏好设置会清除相应阅读设置和阅读历史。

如发现隐私问题，可在项目主页反馈；公开问题描述时请勿附上真实文档、账户资料或访问凭据。
